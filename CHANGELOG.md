# Changelog

## 0.1.0-oss.1

Initial curated MIT source demonstration: Flutter chat UI/controller source,
inert mock entry point, memory-only connection simulation, fictional fixtures,
Android/web hosts, bundled licensed fonts, tests and four genuine app captures.
Live clients, privileged server/supervisor, platform plugins, original artwork
and private Git history are excluded. Browser draft switching updates the input
client before rendering and gives each tab its own input identity.
