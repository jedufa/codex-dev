# Adapting the source

The project is unmaintained and available for adoption. Forks are welcome under
MIT; preserve third-party notices. Keep examples fictional, retain the visible
demo label, and run the boundary check, analyzer, Flutter tests and applicable
browser/native checks before sharing a change. Never commit private paths,
credentials, logs, build outputs or signing keys.

A live backend belongs in a separately reviewed design. This repository does
not include or promise one. Contributions are not guaranteed review or merge.
